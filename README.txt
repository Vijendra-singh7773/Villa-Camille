VILLA CAMILLE WEBSITE
Responsive static website for Villa Camille, Djibouti.

HOW TO VIEW
1. Extract the ZIP.
2. Open index.html in a browser.

CUSTOMIZATION
- Images are in assets/.
- Edit text, links and opening hours in index.html.
- The page uses Google Fonts when internet is available; it falls back to system fonts offline.

Note: Friday hours were not shown in the supplied business information, so the page asks visitors to call and confirm.
